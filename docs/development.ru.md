# Разработка

Это монорепозиторий исходников: `mod/` — многопроектная сборка Gradle, `website/` — отдельное приложение Vite/React и Python API. Тесты из `mod/common/src/test` компилируются для каждой поддерживаемой цели. Необязательные GameTests настоящего клиента включаются через `-PgameTests` и не входят в релизные JAR.

Запустите наборы команд из [README](../README.ru.md). Тесты покрывают определение авторства убийств, монотонное локальное состояние, хранение, ограничения HUD, авторизацию и последовательность снимков, проверку API и сортировку таблицы. Модульные тесты не подтверждают совместимость с обработкой пакетов урона и смерти на каждом сервере.

`tools/demo_site.py` заполняет временную локальную базу SQLite вымышленными игроками и запускает настоящий сайт с API. Скриншоты репозитория используют эти тестовые данные. Первый публичный релиз имеет версию 1.1.4, чтобы отличать его локальные настройки по умолчанию от приватных сборок 1.1.3.
