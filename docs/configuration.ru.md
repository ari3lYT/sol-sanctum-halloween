# Настройка

Мод хранит `config/elysium-halloween/config.json` и `statistics.json` внутри экземпляра игры. Прежние технические имена сохранены для совместимости. Локальным поведением управляют `ordinaryPoints`, `uniquePoints`, `showHud`, `showInTab`, `hudX`, `hudY`, `pollSeconds` и `syncWebsite`. Редактируйте файлы при закрытой игре.

По умолчанию `syncWebsite` имеет значение **false**. Чтобы включить отправку, задайте свой адрес JVM-параметром `-Dsolsanctum.endpoint=https://event.example.com/halloween/api/ingest`, затем включите синхронизацию. Для удалённых серверов разрешён только HTTPS; локальный HTTP на loopback допустим для разработки. Снимки содержат имя и UUID игрока Minecraft, хешированный идентификатор профиля, счётчики события и сведения о версиях. До включения объясните игрокам, какие сведения будут опубликованы. Идентификаторы загрузки и ключи остаются локальными.

API принимает `--host`, `--port`, `--db` и `--public`. `ALLOWED_ORIGINS` — список разрешённых origin через запятую; значение для разработки: `http://127.0.0.1:5186`. Рабочий сервис размещайте за TLS. Базовый путь сайта — `/halloween/`. Внешние запросы аватаров описаны в исходниках интерфейса; при желании замените `Avatar.jsx` локальными заглушками.

После сборки всех версий мода выполните `python tools/prepare_downloads.py` из корня репозитория. Скрипт копирует в каталог скачивания сайта только JAR самого проекта; ссылки Fabric API ведут в официальный Maven-репозиторий Fabric. Не распространяйте старые приватные сборки с другими настройками синхронизации.
