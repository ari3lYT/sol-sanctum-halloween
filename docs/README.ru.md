# Sol Sanctum · Halloween

Здесь исходники клиентского Fabric-мода и сайта рейтинга. Выбери сборку для своей версии Minecraft,
установи соответствующий Fabric API и открой статистику клавишей K. Счётчики сохраняются локально.

Отправка на сайт по умолчанию выключена. Для своего ивента задай собственный endpoint и явно включи
синхронизацию. Это клиентская статистика: сайт не доказывает честность присланных результатов.
Сборка, запуск API и ограничения подсчёта описаны в основном README и документации разработчика.
